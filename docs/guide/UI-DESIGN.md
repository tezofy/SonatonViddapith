# ৩ডি স্টাইল গাইড (v42)

পুরো অ্যাপে একই গভীরতার ভাষা — **হিরো → সেকশন শিরোনাম → কার্ড → চিপ → বাটন → ট্যাববার → প্লেয়ার**।

## মূল ধারণা
প্রতিটি পর্দার উপাদান তিনটি স্তরে তৈরি:
1. **গ্লস** (`--r3-gloss`) — উপরে থেকে সাদা ঝিলিক, ৩৪–৬৪% পর্যন্ত মিলিয়ে যায় (কাচের মতো)।
2. **বেভেল** — `inset 0 1px 0` (উপরের আলো) + `inset 0 -2px 0` (নিচের ছায়া) = উঁচু কী-ক্যাপ।
3. **ড্রপ-শ্যাডো** — দুই স্তরে (`8px/18px` কাছের + `22px/44px` দূরের) = প্লেট ভেসে থাকে।

চাপলে (`:active`) ছায়া **ভেতরে** চলে যায় (`inset 0 3px 7px`) আর উপাদান `translateY(2px)` — হাতে চাপার অনুভূতি।

| `.btn.ghost`, `.chip`, `.pill` | হালকা বেভেল; `.chip.on`-এ সোনালি রিম-গ্লো |

## থিম
সব ছায়া টোকেন-ভিত্তিক (`--r3-hi`, `--r3-lo`, `--r3-shadow`, `--r3-inset`, `--r3-gloss`); ডার্ক (ওয়াইন) ও লাইট (বালু) — দুটোতেই আলাদা করে টিউন করা।

## পারফরম্যান্স ও অ্যাক্সেসিবিলিটি
- শুধু `box-shadow`/`transform` — লেআউট বদলায় না, রিফ্লো হয় না।
- `@media (prefers-reduced-motion: reduce)` — সব ট্রান্সফর্ম ও ট্রানজিশন বন্ধ।
- `backdrop-filter` শুধু অ্যাপবার/ট্যাববার/মিনি-বারে।

## দেখার উপায়
`3d-style-preview.html` — ডার্ক+লাইট পাশাপাশি (হিরো, চিপ, সেগমেন্ট, কার্ড, অডিও প্লেয়ার, ট্যাববার), অ্যাপেরই CSS দিয়ে বানানো।

- **এফেক্ট ৪টি**:

- `prefers-reduced-motion`-এ চারটি অ্যানিমেশনই বন্ধ।

### ১. লোগো

### ৩. ঘুরন্ত বার্তা-লাইন (`#brandline`)
- **প্রতি ৩ সেকেন্ডে** একটি লাইন বদলায় — পরিবর্তনে fade + উঠে আসা + blur (`blIn` .46s)।

- **প্রতি ৪ লাইনের পর** শিশু-শিক্ষার বার্তা **দুই ভাগে**: “আপনার শিশুকে প্রাতিষ্ঠানিক শিক্ষার” (৫s) → “পাশাপাশি ধর্মীয় শিক্ষায় শিক্ষিত করুন।” (৫s) = **১০ সেকেন্ড**, সোনালি রঙ ও বোল্ড।

- স্ক্রিন বদলে ফিরে এলে টিকার নিজে থেকে আবার চালু হয় (`render()`-এর শেষে `brandTicker()`), টাইমার ডুপ্লিকেট হয় না (`clearTimeout`)।

## শেড শুধু উপরের সারিতে (v51)

আগে পুরো `.home-head`-এ লাল-খয়েরি পটভূমি ছিল। এখন **ব্যান্ড শুধু `.hh-row`**-এ (লোগো + “সনাতন বিদ্যাপীঠ” + থিম/বেল বাটন)।

- `.home-head .hh-row` — লাল-খয়েরি গ্রেডিয়েন্ট, নিচে গোল্ড হেয়ারলাইন (`::after`), ছায়া।
- **শুভেচ্ছা · নাম** (`.brandsub`) ও **ঘুরন্ত বার্তা** (`.brandline`) — ব্যান্ডের বাইরে, কোনো শেড নেই; লেখা আবার থিমের নিজের রঙে: শুভেচ্ছা `--gold-400`, নাম `--ink`, বার্তা `--ink-3`, প্রোমো `--gold-300` (লাইটে `#8c2411`)।

## দুই লাইন পুরো ট্রান্সপারেন্ট (v52)

ব্যান্ডের নিচের ছায়া (`.hh-row`-এর `--head-shadow`) নিচের দিকে এক পর্দা লাল-খয়েরি আভা ফেলছিল — সেটাই সরানো হলো:

- `.home-head { background:transparent !important; border:0 !important; box-shadow:none !important; backdrop-filter:none !important }`
- `.hh-row { box-shadow: inset 0 1px 0 var(--head-glow); border-bottom:0 }` — কেবল **ভেতরের** গ্লো, বাইরে ছায়া নেই; `::after` হেয়ারলাইন `display:none`।
- `.brandsub`, `.brandline` → `background:transparent !important; background-image:none !important; border:0 !important; box-shadow:none !important; backdrop-filter:none !important`।
- ওই দুই লাইনে `text-shadow:none`, লেখা থিম-রঙে: শুভেচ্ছা `--gold-400`, নাম `--ink`, বার্তা `--ink-3`, প্রোমো `--gold-300` (লাইটে `#8c2411`)।

## সেটিংস বাটন: আগের ক্রিম ব্যাকগ্রাউন্ড + পপ (v56)

- আইকন তাই **তামা-খয়েরি খোদাই** করা হলো (সোনালি থেকে রঙ-ম্যাপ: `#4a1109 → #96341c → #c46e34`, luminance ধরে রাখা) — ক্রিমের ওপর স্পষ্ট পড়া যায়, খোদাইয়ের ডিটেইল অটুট।

- `prefers-reduced-motion`-এ সব অ্যানিমেশন বন্ধ।

## সেটিংস আইকন = বাকি আইকনের ঘরানা (v57)

- AI বিটম্যাপ (`icons/ai/settings-*.png`) **বাদ**; এখন স্প্রাইটে নতুন ভেক্টর `#i-setgear` — বাকি ৩০+ আইকনের মতোই `<use>` + `stroke: currentColor`।
- আকৃতি: **৮ দাঁতের আসল কগ কনট্যুর** (তীর্যক পলিগন পাথ, `stroke-linejoin:round`), ভিতরে হাব-রিং ও ভরাট কেন্দ্র-বিন্দু — এক নজরে সেটিংস।
- রঙ: ব্র্যান্ড লোগোর রেখার মতোই **গাঢ় মেরুন `#8c2411`** (hover-এ `#6f1a0c`), ক্রিম টাইলের ওপর — ঠিক ব্যান্ড-আইকনের পরিবার।

- hover/ক্লিকে ৪০° ঘোরে; পপ-অ্যানিমেশন আগের মতোই।
- লাভ: যেকোনো DPI-তে ঝকঝকে (বিটম্যাপ রিস্কেলিং নেই), ব্যাকগ্রাউন্ড কী করার ঝামেলাও নেই।

## সেটিংস = ছোট পপআপ (v58)

আগে গিয়ারে চাপ দিলে আলাদা পর্দায় (`#/settings`) যেত। এখন **বাটনের নিচে ড্রপ-পপআপ** খোলে — পর্দা বদলায় না।

- ইঞ্জিন: `openSetPop()` / `refreshSetPop()` / `closeSetPop()`; হোস্ট `#setPop` (প্রথম বার `document.body`-তে তৈরি হয়)।
- মার্কআপ: `.setpop` → `.setpop-bg` (void-এ `data-act="setPopupClose"`) + `.setpop-card` (dialog)।
- ভিতরে: **থিম সেগমেন্ট** (`☀ লাইট` / `🌙 ডার্ক`) + `prefCard()`-এর সব সারি (পটভূমি, ধ্বনি, অ্যানিমেশন, নাম, রিসেট) — একই অ্যাকশন, নতুন কোড নয়।
- অবস্থান: `top:72px; right:14px; width:min(330px, 100vw-28px)`, `transform-origin: top right`, `setPopIn` (০.৯০ স্কেল + −১০px থেকে ১.০১২ হয়ে স্থির), উপরে ছোট **সূচক তীর**।
- `render()` শেষে `refreshSetPop()` — থিম/টগল বদলালে পপআপ খোলাই থাকে ও সেগমেন্ট আপডেট হয়।
- **Esc** বা ব্যাকড্রপে বন্ধ; খোলা থাকলে `body.setpop-lock { overflow:hidden }`।
- `#/settings` রুটটি ডিপ-লিঙ্কের জন্য আগের মতোই আছে।

## নিচের নেভিগেশন বার: ছোট + হেডারের লাল-খয়েরি (v59)

## ট্যাববার আইকন: পরিষ্কার ভেক্টর + ক্রিম সক্রিয় টাইল (v60)
