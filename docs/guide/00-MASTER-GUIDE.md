# সনাতন বিদ্যাপীঠ (Sanatan Biddapith)
## সম্পূর্ণ মাস্টার গাইড — ভিশন থেকে লঞ্চ পর্যন্ত (সংস্করণ ১.০)

> **উৎস:** আপনার দেওয়া ধারণা + সনাতন বিদ্যাপীঠ ফেসবুক গ্রুপ/পেজের পরিচিত কার্যক্রম (ধর্মশাস্ত্র অধ্যায়ন, স্তোত্র, নারীশক্তি ঐক্যমিলন, সেবামূলক উদ্যোগ)।
> **নোট:** ফেসবুক গ্রুপের ভেতরের পোস্টগুলো (লগইন-প্রাচীরের কারণে) সরাসরি পড়া যায়নি, তাই এই গাইড আপনার বর্ণনা ও পাবলিক তথ্যের ভিত্তিতে তৈরি। আপনি চাইলে গ্রুপের স্ক্রিনশট/কপি দিলে কনটেন্ট ম্যাপ আরও নিখুঁতভাবে মেলানো যাবে।

## ১. ধারণার পুনর্গঠন — আমরা আসলে কী বানাচ্ছি?

### ১.১ গ্রুপ → প্লাটফর্ম (কী বদলাচ্ছে)
ফেসবুক গ্রুপ হলো **আড্ডা + ঘোষণা**। প্লাটফর্ম হবে **শৃঙ্খলা + মূল্য**।
তিনটি রূপান্তর স্পষ্টভাবে করতে হবে:

1. **খণ্ডিত পোস্ট → ক্রমবিন্যস্ত পাঠ্যক্রম** (Level → Course → Lesson → Quiz)
2. **মন্তব্যের বিশৃঙ্খলা → সংগঠিত সেবা ও মার্কেটপ্লেস** (রিকোয়েস্ট → ম্যাচিং → এসক্রো পেমেন্ট → রিভিউ)
3. **স্বেচ্ছাসেবার আবেগ → টেকসই আয়ের ইকোসিস্টেম** (কনট্রিবিউটর আয় করে, প্লাটফর্ম কমিশন পায়, সেবা চলে)

### ১.২ মাস্টারমাইন্ড ফ্রেমওয়ার্ক (কোন টুল কখন ব্যবহার করব)
| ফ্রেমওয়ার্ক | এখানে প্রয়োগ |
|---|---|
| **First Principles** | “ধর্মীয় মানুষটির আসল চাহিদা কী?” — শাস্ত্র জানা, আচার ঠিকভাবে করা, সন্তানকে শেখানো, শুভ সময় জানা, বিপদে সহায়তা। ফিচার নয়, চাহিদা থেকে শুরু। |
| **Jobs-To-Be-Done (JTBD)** | “আমি যখন সকালে পূজা করি, তখন আমি নিশ্চিত হতে চাই ধাপগুলো সঠিকভাবে করছি।” → গাইডেড পূজা মোড |
| **North Star Metric** | WAL (Weekly Active Learners) — ভ্যানিটি মেট্রিক (লাইক/ফলোয়ার) নয় |
| **MoSCoW** | Must / Should / Could / Won't — ফিচার জমা বাড়লেও স্কোপ নিয়ন্ত্রণে রাখে |
| **RICE স্কোরিং** | Reach × Impact × Confidence ÷ Effort — কোন ফিচার আগে |
| **AARRR (Pirate Metrics)** | Acquisition (গ্রুপ/রিল), Activation (১ম পাঠ), Retention (স্ট্রিক), Revenue, Referral |
| **Pre-mortem** | “৬ মাসে প্রজেক্ট ফেল করলে কেন?” — আগেই উত্তর লিখে প্রশমন করা |
| **Second-order thinking** | “ইনকাম বাড়াতে বিজ্ঞাপন দিলে?” → ২য় ক্রম: ধর্মীয় কনটেন্টে বিজ্ঞাপন = আস্থা নষ্ট। তাই সাবস্ক্রিপশন-ভিত্তিক মডেল। |
| **Build–Measure–Learn** | প্রতি ২ সপ্তাহে ছোট রিলিজ, ব্যবহারকারীর সাথে যাচাই |

### ১.৩ এক লাইনের পজিশনিং স্টেটমেন্ট
> **যাদের জন্য:** বাংলাভাষী সনাতন ধর্মাবলম্বী পরিবার ও শিক্ষার্থী
> **যারা:** গ্রুপে ছড়ানো, অসংগঠিত ও যাচাই-অযাচাই মিশ্র ধর্মীয় কনটেন্টে আস্থা হারাচ্ছে
> **আমাদের প্লাটফর্ম:** একটি শাস্ত্রীয় পরিষদ-যাচাইকৃত একাডেমি + সেবা + রোজগার প্লাটফর্ম
> **যা দেয়:** শুদ্ধ জ্ঞান, ধাপে ধাপে পাঠ, পরীক্ষায় স্বীকৃতি, আর দক্ষ সনাতনীদের জন্য সম্মানজনক আয়
> **যা আলাদা করে:** শুধু “কনটেন্ট” নয় — **স্বীকৃত পাঠ্যক্রম + নৈতিক ইনকাম ইকোসিস্টেম**

## ৩. ভালো-মন্দ বিচার (সৎ বিশ্লেষণ)

### ৩.১ শক্তি ও সুবিধা
1. **অতুলনীয় নিশ (Niche)**: বাংলাভাষী সনাতন শিক্ষা + সেবা + রোজগার — একসাথে কেউ করছে না।
2. **তৈরি সম্প্রদায়**: গ্রুপ/পেজের অনুসারীই প্রথম ১,০০০ ব্যবহারকারী — শূন্য থেকে শুরু করতে হবে না।
3. **নেটওয়ার্ক ইফেক্ট**: শিক্ষক যত বেশি → শিক্ষার্থী তত বেশি → আয় তত বেশি → শিক্ষক আরও বেশি।
4. **উচ্চ প্রতিশ্রুতি (Devotion-driven retention)**: ধর্মীয় কনটেন্টে দৈনিক ব্যবহারের অভ্যাস তৈরি হয়।
5. **কম খরচে MVP**: আধুনিক স্ট্যাক দিয়ে ৳৫০–৮০ হাজারে কার্যকর MVP সম্ভব।
6. **বহুমুখী আয়**: একটির উপর নির্ভরশীল নয়।

### ৩.২ দুর্বলতা ও ঝুঁকি (অসুবিধা)
1. **ধর্মীয় ভুলের শাস্তি কঠিন**: একটি ভুল মন্ত্র/পদ্ধতি ছড়ালে সম্প্রদায় ক্ষমা করে না → প্রাতিষ্ঠানিক পর্যালোচনা বাধ্যতামূলক।
2. **মডারেশন-ভারী**: ধর্ম + অর্থ + মানুষের আবেগ = প্রতিদিন বিরোধ মেটাতে হবে (এটি খরচ, ফিচার নয়)।
3. **পেমেন্ট বাধা**: অভিভাবক/গৃহিণীদের জন্য অনলাইন পেমেন্টের অভ্যাস কম; bKash/Nagad + ক্যাশ-এজেন্ট হাইব্রিড লাগবে।
4. **ট্রাস্ট-ডেফিসিট**: নতুন প্লাটফর্মে টাকা রাখা মানে বিশ্বাস রাখা → এসক্রো ও রিফান্ড নীতি স্পষ্ট করতে হবে।
5. **কপিরাইট**: পুরাণ/গীতা মূল টেক্সট পাবলিক ডোমেইন হলেও **অনুবাদ ও ভাষ্য** প্রায়ই কপিরাইটেড → নিজস্ব অনুবাদ বা লাইসেন্স নিতে হবে।
6. **সাম্প্রদায়িক ট্রিগার**: তুলনামূলক ধর্মতত্ত্ব/বিতর্কমূলক কনটেন্ট প্লাটফর্মের অস্তিত্ব সংকটে ফেলতে পারে → নীতি: **শিক্ষা হ্যাঁ, বিদ্বেষ নয়**।
7. **মৌসুমি ট্রাফিক**: পূজা/উৎসব কেন্দ্রিক চাহিদা ওঠানামা করে → বার্ষিক সাবস্ক্রিপশন দিয়ে মসৃণ করতে হবে।
8. **দক্ষ জনবলের অভাব**: শাস্ত্রজ্ঞ + ডেভেলপার + মডারেটর একসাথে পাওয়া কঠিন।
9. **দাতা-নির্ভরতার ফাঁদ**: সেবা মডিউল যদি দানের উপর দাঁড়ায়, আয় মডিউল দাঁড়াবে না → দুটিকে আলাদা খাতায় রাখতে হবে (নিচে ৭.৪)।

## ৫. ধর্মীয় নির্ভুলতা ও কনটেন্ট গভর্নেন্স (প্লাটফর্মের হৃদয়)

### ৫.১ তিন স্তরের পর্যালোচনা (Content Pipeline)
```
আইডিয়া/জমা → সম্পাদনা (ভাষা) → শাস্ত্রীয় পর্যালোচনা (২ জন স্বতন্ত্র) → প্রকাশ → ব্যবহারকারী ফিডব্যাক → সংশোধন (ভার্সন লগ)
```
- প্রতিটি শ্লোক/মন্ত্রে **সূত্র**: গ্রন্থ, অধ্যায়, শ্লোক নম্বর, অনুবাদকারী, সংস্করণ।
- **ভুল সংশোধনের রেজিস্টার** (Public errata) — স্বচ্ছতা = আস্থা।
- বিতর্কিত বিষয় (যেমন নারী-আচার, বর্ণ, মূর্তিপূজা-বিতর্ক) → **একাধিক দর্শনের মত পাশাপাশি**, কিন্তু সিদ্ধান্ত চাপিয়ে না দেওয়া।

### ৫.২ শাস্ত্রীয় পর্যালোচনা বোর্ড
- ৩–৫ জন: ১ জন সংস্কৃত/শাস্ত্রজ্ঞ, ১ জন ভাষাবিদ, ১ জন পণ্ডিত-শিক্ষক, ১ জন সম্পাদক।
- সম্মানী: প্রতি পর্যালোচনায় ৳৩০০–১০০০ (টুকটাক) — শুরুতে স্বেচ্ছাসেবা + স্বীকৃতিপত্র।
- প্রতিটি প্রকাশিত এককের **কৃতিত্ব (author credit)** — শিক্ষকদের জন্য এটাই বড় প্রণোদনা।

### ৬.২ রেভিনিউ শেয়ার মডেল (কনট্রিবিউটরদের জন্য)
```
টিউশন/সেবা লেনদেন ৳১০০০
 ├── শিক্ষক/সেবাদাতা: ৮৫% → ৳৮৫০
 ├── প্লাটফর্ম: ১২% → ৳১২০ (হোস্টিং, পেমেন্ট ফি, মডারেশন, মার্কেটিং)

```
- **কোর্স রয়্যালটি:** শুধুমাত্র-প্রিমিয়াম কোর্সের সাবস্ক্রিপশন রেভিনিউ শিক্ষার্থীর ব্যবহার-ভিত্তিক ভাগ (উদাহরণ: লেসন পূর্ণ হলে শিক্ষককে পুল থেকে ভাগ) — শুরুতে সরল রাখুন: বিক্রয়-ভিত্তিক (কোর্স আলাদা দামে বিক্রি) ৭০/৩০।
- **পেআউট চক্র:** সপ্তাহে ১ বার (রবিবার), ন্যূনতম ৳৫০০।
- **কমিশন পেনি-দেখানো UI:** স্বচ্ছ ফি ব্রেকডাউন দেখানো বাধ্যতামূলক।

### ৬.৪ ইনকাম ইকোসিস্টেমের নিয়ম (Circular Economy of Trust)
1. **কনট্রিবিউশন = ক্রেডিট**: কনটেন্ট/পর্যালোচনা/সেবায় পয়েন্ট → প্রিমিয়াম ফিচার আনলক।
2. **শেখা → রোজগার পথ**: কোর্স সম্পন্ন → স্কিল ব্যাজ → মার্কেটপ্লেসে যোগ্যতা (যেমন “গ্রাফিক্স বেসিক” কোর্স শেষ = ডিজাইন জব ফিডে প্রবেশ)।
3. **লোকাল ইকোনমি**: মন্দির-কেন্দ্রিক পূজা সামগ্রী বিক্রেতাকে অনবোর্ড করা।
4. **এক্সিলেন্স পুরস্কার**: মাসের সেরা ৩ শিক্ষক → সম্প্রদায়ে স্বীকৃতি + ফিচার্ড কোর্স (ফ্রি দিন)।
5. **স্বচ্ছ ব্যালান্স শিট**: শিক্ষক দেখতে পাবে কত আয়, কত কমিশন, কত পেআউট।

## ৭. সেবা (Seva) মডিউলের গঠন ও সীমা

### ৭.১ সেবা পণ্য
- **শিশু আহার #ShishuAhar** — মাসিক ৳৫০০/৭৫০ = ১ শিশুর ১ মাসের দুপুরের আহার (স্কুল-পার্টনারশিপ)

- **শীতবস্ত্র ও বস্ত্রদান** (মৌসুমি ক্যাম্পেইন)
- **বিনামূল্যে বই/স্তোত্র বিতরণ** (ডিজিটাল ফ্রি, প্রিন্ট ক্যাম্পেইন)
- **মেডিকেল ক্যাম্প / রক্তদান নেটওয়ার্ক**

- প্রতিটি ক্যাম্পেইনে: লক্ষ্য, খরচের ব্রেকডাউন, ছবি/রিসিট আপলোড, অডিট রিপোর্ট (ত্রৈমাসিক)।

- **অডিট কমিটি** (৩ জন, সম্প্রদায় থেকে) — ত্রৈমাসিক প্রতিবেদন প্রকাশ।

### ৭.৩ সীমা (কী করব না)

- ব্যক্তিগত ক্যাশ সংগ্রহ (শুধু প্লাটফর্ম চ্যানেল)
- রাজনৈতিক বা দলীয় ব্যবহার
