# গীতার বাংলা অডিও পাঠ — যথার্থ গীতা

লাইব্রেরির **“অডিও”** ট্যাবে আগে ছিল “অডিও পাঠ শীঘ্রই আসছে” প্লেসহোল্ডার। এখন সেখানে **১৮টি অধ্যায় + উপসংহার** — মোট ১৯টি সম্পূর্ণ বাংলা অডিও, অ্যাপের ভেতরেই প্লে হয়।

## উৎস ও যাচাই

- চ্যানেল: **Yatharth Geeta - ASHRAM** — <https://www.youtube.com/@yatharthgeeta-official>
- কীভাবে পাওয়া গেল: চ্যানেলের ভেতরের সার্চ (`/@yatharthgeeta-official/search`) বাংলা/Bangla/Bengali কোয়েরিতে ২৯টি ফলাফল আসে; তার মধ্যে বাংলা শিরোনামের ১৯টি (১৮ অধ্যায় + উপসংহার) বেছে নেওয়া হয়েছে।
- **প্রতিটি ভিডিও আইডি oEmbed দিয়ে যাচাই করা** (`youtube.com/oembed`) — সবগুলোর চ্যানেল “Yatharth Geeta - ASHRAM” ও শিরোনাম অধ্যায়ের সঙ্গে মিলেছে।
- একই অধ্যায়ের ডুপ্লিকেট আপলোড (যেমন ষষ্ঠ অধ্যায়ের দুটি সংস্করণ) থেকে **বেশি-শোনা/দীর্ঘ সংস্করণটি** রাখা হয়েছে।
- সংরক্ষণ: `app/js/data.js → gitaAudio` — `{ ch, id, name, dur }` (ch = 0 মানে উপসংহার)।

## অডিও প্লেয়ার (নতুন)

ভিডিও এমবেডের বদলে এখন **আসল অডিও-প্লেয়ার** — YouTube IFrame API দিয়ে চলে, ভিডিও পর্দা নেই, শুধু শব্দ:

| কন্ট্রোল | কী করে |
|---|---|
| ▶ / ❚❚ | চালান / থামান (বড় বাটন ও মিনি-বার — দুটোতেই) |
| সিক-বার | যেকোনো জায়গায় টেনে দেওয়া (আসল সময় অনুযায়ী) |
| ↺১৫ / ১৫↻ | ১৫ সেকেন্ড পিছনে / সামনে |
| ◀◀ / ▶▶ | আগের / পরের অধ্যায় |
| 🔊 ভলিউম | স্লাইডার (পছন্দ `audioVol` হিসেবে সেভ থাকে) |
| ১× গতি | ১× → ১.২৫× → ১.৫× → ০.৭৫× (`setPlaybackRate` — আসল গতি) |
| ✕ | বন্ধ |

- প্লেয়ার **একবারই তৈরি হয়**, পর্দার বাইরে (`#ytHost`) থাকে — তাই পাতা বদলালেও **অডিও চলতে থাকে**।
- সব পর্দায় নিচে **মিনি-প্লেয়ার বার**: অধ্যায়ের নাম, সময়, ◀ ❚❚ ▶ ✕ ও প্রগ্রেস-রেখা।
- সময় বাংলা অঙ্কে (যেমন `০:৪২ / ১:২৫:০৮`); ভলিউম-বার মিনি-বাটন `+` বাটনকে উপরে সরিয়ে দেয় যাতে ওভারল্যাপ না হয়।
- ইন্টারনেট না থাকলে বা API ব্লক হলে অডিও চালু হবে না — ততক্ষণ “ইউটিউবে ↗” বাটন আছে।

## অ্যাপে কীভাবে চলে

- **ক্যাটাগরি-চিপ**: `সব ১৮` · `অধ্যায় ১–৬` · `অধ্যায় ৭–১২` · `অধ্যায় ১৩–১৮` · `উপসংহার`
- যেকোনো অধ্যায়ে ট্যাপ → উপরে **অডিও কার্ড** (থাম্বনেইল, শিরোনাম, বড় ▶, সিক-বার, সময়, ↺১৫/১৫↻, আগের/পরের, ভলিউম) — শব্দসহ চালু হয়
- চলমান অধ্যায়ের কার্ডে **“▶ চলছে”** চিহ্ন
- সংখ্যা বাংলায় (১–১৮), দৈর্ঘ্য ঘণ্টা:মিনিট:সেকেন্ড বাংলা অঙ্কে
- ভিডিও ফাইল অ্যাপে রাখা হয় না — শুধু লিংক, তাই অ্যাপের আকার বাড়েনি

## লেআউট-সুরক্ষা (১৮ নভে ২০২৬)

মিনি-প্লেয়ার বার **inline style** নিয়েই তৈরি হয় (`position:fixed; bottom:78px`; `display` শুধু দরকারে `flex`) — কারণ `body` নিজেই `display:flex`, তাই CSS না পড়লে বার flex-আইটেম হয়ে পুরো পাতা চেপে দিচ্ছিল। এখন CSS পুরোনো ক্যাশে থাকলেও লেআউট ঠিক থাকবে; সঙ্গে `sw.js` ক্যাশ-সংস্করণ `v3`।

## ডিজাইন আপগ্রেড (১৮ নভে ২০২৬, v47/v40)

- থাম্বনেইলের ঝাপসা গ্লো-ব্যাকড্রপ, বড় সোনালি ▶/❚❚, কিকার + সেরিফ শিরোনাম।
- থাম্বনেইলে **ইকুয়ালাইজার বার** + “চলছে” পালস-ডট — শুধু বাজলে দেখায় (`.apl.playing`)।
- সিক-বার: `--p` কাস্টম-প্রপার্টি দিয়ে গোল্ড ফিল, সাদা নব; সময় দুই প্রান্তে; ≥১ ঘণ্টা হলে `ঘ:মম:সস`।
- নিয়ন্ত্রণ: ↺১৫ · ◀◀ · ▶▶ · ১৫↻ · গতি-বাটন; ভলিউম আলাদা সারিতে।
- ভিজ্যুয়াল যাচাই: `audio-player-preview.html` (ডার্ক+লাইট, থাম্বনেইল base64) — অ্যাপেরই CSS/মার্কআপ দিয়ে বানানো।
- **খেয়াল**: গতি ও ভলিউম প্লেয়ারে বসে `onReady`-তে; নতুন ভিডিওতে গতি বজায় থাকে।
