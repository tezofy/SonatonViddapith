## ৩. ব্যবহার

1. পূজা পাতা → “দেবদেবীর পূজা · ধাপে ধাপে” গ্রিড থেকে দেবতা বাছুন।
2. বেদির নিচে **চলতি ধাপ** দেখা যায় — কী করতে হবে, মন্ত্র, আর ডান পাশে “উচ্চারণ শুনুন”।
3. **উপকরণের থালা**-তে সোনালি রিং-এ চিহ্নিত উপকরণে চাপ দিন → ধাপ এগোবে, বেদিতে তার প্রতিক্রিয়া (প্রদীপ জ্বলে, পাপড়ি জমে…)।
4. শেষে “পূজা সম্পূর্ণ 🌸” + “আবার শুরু” / “আরেক দেবতা”।

## ৪. সংরক্ষণ

- `localStorage` কী **`svp_deva`**; ভিতরে `{ "<দেবতা-id>:<YYYY-MM-DD>": [ধাপ-সূচি…] }`।
- দিন বদলালে (`TODAY_KEY`) নতুন পূজা হিসেবে গণ্য — কার্ডে ০% থেকে শুরু।
- কার্ডের বার ও “X/Y ধাপ · Z%” একই ডেটা থেকে।

## ৫. সীমা (সৎ নোট)

- ধাপের ক্রম **সাধারণ/প্রচলিত** পূজা-পদ্ধতি; সম্প্রদায়-ভেদে (বৈষ্ণব/শাক্ত/স্মার্ত) ক্রম ও সংখ্যা ভিন্ন হয়।
- মন্ত্রগুলো **সংক্ষিপ্ত বীজ/নাম মন্ত্র ও সুপরিচিত শ্লোক**; পূর্ণ বিধি (ন্যাস, কল্প, ষোড়শোপচার সম্পূর্ণ রূপ, সংস্কার) এখানে নেই।
- **কারিগরি করে তৈরি করা কোনো তথ্য নেই** — সব মন্ত্র প্রচলিত পাঠ; যেখানে পাঠ নিয়ে সংশয়, সেখানে শুধু প্রসিদ্ধ রূপটিই রাখা হয়েছে।
- ভাচুর্য়াল উপকরণ **প্রতীকী** — সত্যিকারের উপকরণ/মূর্তি-স্থাপনার বিকল্প নয়; বিগ্রহ-স্থাপনা, বিশেষ ব্রত বা অসুস্থতায় পুরোহিতের পরামর্শ নিন।
- TTS ব্রাউজার-নির্ভর — উচ্চারণ যন্ত্রভেদে ভিন্ন হতে পারে; কোনো ব্রাউজারে বাংলা ভয়েস না থাকলে শুধু বার্তা দেখাবে।

## ১১. ঠিক করা (v79)

- **পুরনো নিয়ম মোছা:** v77 + v78-এর CSS ব্লক বাদ দিয়ে একটাই ব্লক — তাই আর কোনো specificity-সংঘর্ষ নেই।
- **ছবি দেখানোর তিন স্তর:** `onload="this.parentNode.classList.add('has-art')"` (ইনলাইন, JS-এর অপেক্ষা নেই) → `onerror="this.remove()"` → `?v=79` ক্যাশ-বাস্ট। আইকন ৩০px।
- **পোস্টার-নিষ্ঠা:** `.tside-it` = row কার্ড (নম্বর-বৃত্ত · ৩০px ছবি · নাম · ব্যাখ্যা), `.tcore` = দুই কলামের মাঝে উল্লম্ব-কেন্দ্রিক মূর্তি + খিলান + বেদি, `.m-wide` = শেষ ধাপ, `.m-legend` = ৫ টাইল, `.m-foot` = ব্র্যান্ড।
- **ব্যাকগ্রাউন্ড-স্তর নেই:** `#pujabg`, `data-puja`, `pujaFocus` — সব বাদ।
- **যাচাই:** ৫৫ চেক + ২০ রুটে ০ এরর; প্রিভিউতে ৫৮টি ছবির স্লট ভরা।

## ১২. হাতে টেনে অর্পণ (v80)

প্রতিটি উপকরণ এখন **আঙুলে ধরে টেনে মূর্তির উপর ছাড়লেই** অর্পিত হয় — আরতির আসল অনুভূতি।

| বিষয় | নিয়ম |
|---|---|
| শুরু | `.tside-it`-এ `pointerdown` (মাউস/টাচ/পেন একই পথে) |
| থ্রেশহোল্ড | `｜dx｜ > ১০px` **এবং** `｜dx｜ > ｜dy｜` — তবেই ধরা শুরু; উল্লম্ব টানে পেজ স্ক্রল করে (`touch-action:pan-y`) |
| ভাসমান ছবি | `div.drag-ghost` (`position:fixed`, `pointer-events:none`) — ৩৪px উপকরণ-ছবি + নাম |
| লক্ষ্য | `document.elementFromPoint` → `.tcore` (২৬px প্যাডিং সহ হিট-টেস্ট) → `.hot` + `.tcore.drop-hot` |
| ছাড়া | সঠিক হলে `offerStep()`: ঘণ্টা (.45), টোস্ট “অর্পিত ✓”, `flyOffering()`, `render()`; ভুল/ফাঁকা জায়গায় নরম ঘণ্টা (.25) + “এই ধাপে দরকার: …” |
| ডাবল-ক্লিক | টানের পরের `click` **৪০০ms** ধরা হয় (`swallowClick`) — এক টানে এক ধাপ |
| ট্যাপ | আগের মতোই কাজ করে — প্রতিবন্ধকতা/কীবোর্ডের বিকল্প পথ |
| ৩ডি | `.tpl` `perspective:900px`, কার্ড `rotateY(±9deg)`, মূর্তি `translateZ(30px)`, হ্যালো `−24px`; `prefers-reduced-motion`-এ বন্ধ |

**ব্রাউজার-ক্যাশ:** CSS/JS বদলেছে (`?v=80`) ও সার্ভিস-ওয়ার্কার `sanatana-v44`; পুরনো নিয়ম আটকে থাকলে **হার্ড-রিফ্রেশ** (Ctrl+Shift+R) দিন।
