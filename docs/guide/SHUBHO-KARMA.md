# শুভকর্মের দিন — ১৭টি সংস্কার (পঞ্জিকা → “শুভকর্মের দিন”)

## কোন কোন কাজ
দীক্ষা · গৃহারম্ভ · গৃহপ্রবেশ · দেবগৃহারম্ভ · দেবগৃহপ্রবেশ · ভূমি ক্রয়-বিক্রয় · গাত্রহরিদ্রা · গর্ভাধান · পঞ্চামৃত · সাধভক্ষণ · অন্নপ্রাশন · উপনয়ন · বিষ্ণুপ্রতিষ্ঠা · শিবপ্রতিষ্ঠা · বৃষপ্রতিষ্ঠা · শান্তিস্ব্যন্ত্যায়নাদি · গ্রহপূজা।

প্রতিটি কার্ডে: **পরের শুভ দিন + কত দিন বাকি + সেই দিনের তিথি ও নক্ষত্র + পরের আরও দুটি দিন।**

## গণনার নিয়ম (সরল ও প্রকাশ্য)
প্রতিটি কাজের জন্য তিনটি শর্ত একসঙ্গে মিললে দিনটি শুভ ধরা হয় —

| উপাদান | নিয়ম |
|---|---|
| **তিথি** | ২, ৩, ৫, ৭, ১০, ১২, ১৩ (শুক্লা-কৃষ্ণ উভয় পক্ষে) |
| **বর্জিত তিথি** | ৪র্থী, ৬ষ্ঠী, ৮মী, ৯মী, ১১শী (একাদশী), ১৪শী, পূর্ণিমা, অমাবস্যা |
| **বার** | কাজভেদে সোম/বুধ/বৃহঃ/শুক্র (গৃহ-প্রতিষ্ঠায় বৃহঃ-শুক্র প্রাধান্য), ভূমিক্রয়ে শনিবারও |
| **নক্ষত্র — স্থির** | রোহিণী · উত্তরফাল্গুনী · উত্তরাষাঢ়া · উত্তরভাদ্রপদ → গৃহ, প্রতিষ্ঠা, অন্নপ্রাশন |
| **নক্ষত্র — মৃদু** | মৃগশিরা · চিত্রা · অনুরাধা · রেবতী → দীক্ষা, গাত্রহরিদ্রা, সাধভক্ষণ |
| **নক্ষত্র — ক্ষিপ্র** | অশ্বিনী · পুষ্যা · হস্তা · স্বাতী · ধনিষ্ঠা → ভূমিক্রয়, অন্নপ্রাশন |
| **উপনয়ন** | শুধু মাঘ–জ্যৈষ্ঠ মাসে, স্থির নক্ষত্রে |
| **সব কাজে বর্জিত দিন** | একাদশী, অমাবস্যা, পূর্ণিমা ও সংক্রান্তির দিন |

তিথি-নক্ষত্র সূর্যোদয়ের মুহূর্তে গণনা করা হয় (Meeus নিম্ন-নির্ভুল সূর্য-চন্দ্র সিরিজ)।

> এটি **নির্দেশক** তালিকা। বিয়ে, প্রতিষ্ঠা বা গৃহপ্রবেশের পূর্ণাঙ্গ মুহূর্তের জন্য **লগ্ন, যোগ-করণ, অষ্টমাঙ্গ ও স্থানীয় পঞ্জিকা** মিলিয়ে পণ্ডিত/পুরোহিতের পরামর্শ নেওয়া উচিত।
