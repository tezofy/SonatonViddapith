# ধর্মীয় আইকন সেট — ৩১টি

প্রতিটি আইকন হাতে আঁকা (ভেক্টর) — হিন্দু-ধর্মীয় চিহ্ন থেকে ভাব নেওয়া, এবং **যে বাটনে বসে তার নিজের থিম** অনুযায়ী।
সব আইকন `24×24` `viewBox`, **স্ট্রোক-ভিত্তিক** (`fill:none; stroke:currentColor`), তাই লাইট ও ডার্ক দুই মোডেই নিজে থেকেই মানানসই।

- স্প্রাইট: `app/js/app.js` → `SPRITE` (৩১টি `<symbol id="i-…">`)
- সিএসএস: `app/css/app.css` → `.ico` · `.ico.sm` · `.ico.xs` (লাইট মোডে স্ট্রোক কিছুটা মোটা)
- ব্যবহার: `<svg class="ico"><use href="#i-flame"></use></svg>`
- প্রিভিউ: `docs/guide/icons-preview.html` · `icon-set-light.png` · `icon-set-dark.png`

## অ্যাপ/ব্র্যান্ড আইকন

`app/icons/icon-light.png` · `app/icons/icon-dark.png` — তোরণ-আকৃতির মন্দির-খিলানে ॐ, নিচে পদ্ম, উপরে প্রদীপ-শিখা।
ম্যানিফেস্টে ১৯২/৫১২ দুটোই আছে (maskable + monochrome সহ)। হোমের শিরোনামে ছোট ব্র্যান্ড-চিহ্ন থিমের সঙ্গে বদলায়।

## এআই-জেনারেট ব্র্যান্ড আইকন (১৭টি)

পটভূমি ছাড়া লাইন-আর্ট; প্রতিটির **দুই রঙের ফাইল** — `app/icons/ai/<নাম>-light.png` (তামা-লাল) ও `<নাম>-dark.png` (সোনালি)। থিম অনুযায়ী `<img>` বসে।
